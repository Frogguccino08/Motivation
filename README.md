# Jogo Motivacional

Este pequeno projeto é uma forma amigável de pessoas com dificuldade com foco se concentrarem no que estão fazendo. Ele utiliza de um método, ganhando recompensa (Tempo de descanso) por horas trabalhadas.

Como funciona:
- O usuário inicia o relógio dentro do aplicativo.
- A cada 15 minutos de trabalho uma recompensa é recebida na forma de uma esfera entre 3 opções aleatóriamente.
- Juntando 3 esferas iguais é recebido tempo de descanso.
- Clicando em "Usar horas é gasto tempo do seu tempo de descanso ao invés de prosseguir o relógio.

Colocando o descanso como uma recompensa o usuário instintivamente tende a focar mais no seu trabalho esperando receber a recompensa por se manter concentrado. Um método muito utilizado por crianças e paciêntes com TDAH.
